## 方舟服务台 - 工单管理系统 (Sprint 1)

 项目简介
本项目是 Sprint 1 阶段的交付成果，是一个基于 Vue 3 + Vite 构建的前端工单管理系统。系统实现了从工单创建、列表检索到工单详情查看的完整闭环流程。

当前版本默认采用 Mock 模式，数据保存在浏览器的 `localStorage` 中，无需连接后端即可独立运行和演示。

##  核心功能
- 工单中心：支持关键字搜索、按状态筛选、分页/列表展示（含状态与优先级徽标）。
- 创建工单：表单双向绑定，包含必填校验、字符长度限制及实时登记摘要预览。
- 工单详情：展示工单基础信息，并通过时间轴（Timeline）展示操作记录。
- 响应式设计：完美适配 PC、平板及手机端布局。
- **友好交互**：包含 Loading 加载态、错误重试提示、空数据状态以及全局 Toast 提示。

##  技术栈
- 前端框架：Vue 3 (Composition API / `<script setup>`)
- 构建工具：Vite
- 路由管理：原生 `window.location.hash` 轻量级路由
- 样式：原生 CSS (Grid / Flexbox)
